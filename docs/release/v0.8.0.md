# form-net v0.8.0 - Alpha

**Date:** 2026-11-07
**Compare:** [`v0.7.0...v0.8.0`](https://github.com/jamesgober/form-net/compare/v0.7.0...v0.8.0)

**The first site's two routes, written against form-net.** v0.8.0 adds what a framework needs to run a login form and an upload safely: an anti-forgery check that refuses a forged upload before any file reaches disk, and a per-route count of every refusal for the detection layer. Writing the routes found two problems, both fixed: a content check that failed open under the default limits, and a typed form that would not compile when private.

## What changed

- **`TokenCheck`** (D-120): an inspector that verifies the anti-forgery token the moment its field ends. A file part before a verified token, a body without one, and a second token are refused with 403. It works for urlencoded forms too, and composes with other inspectors as a pair. The comparison is the caller's (csrf-sec's `Csrf::verify`); form-net has no dependency on csrf-sec.
- **`RefusalDigest`** (D-123): how many times each error code was returned, per route. One relaxed atomic add per record (5 ns), no allocation, no lock; a `static` per route works. Built on every target with atomic adds.
- **The sniff window is on by default** (D-122): `Limits::DEFAULT.sniff_bytes` is 512, was 0. Under 0, an inspector's `sniff` was never called, so a route that forgot to set it let a GIF through as a PNG. 0 still turns it off. A file's first 512 bytes reach the sink when the window is full or the part ends.
- **`form!`** (D-121): the hidden builder takes the struct's visibility, so a private form at module level compiles.

## Verification

- `tests/token_check.rs`: csrf-sec 0.9.1's real tokens through every chunk split of an upload. A forged token (another key, another session, not a token, empty) stops the upload before any file byte; no file is ever created.
- `tests/alpha_routes.rs` (D-124): the login and avatar routes as web-net will write them, with a test double for customs-sec. Every refusal lands in the route's digest under its code.
- The T-7 shared-budget test holds its first round, so the budget is always tested.
- Local gate on Windows and WSL Ubuntu, stable and 1.85; CI green on every platform before the tag.

## Performance

- `TokenCheck` on a login form: 268 ns against 257 ns without it (`verify` excluded).
- `RefusalDigest::record`: 5 to 6 ns.
- The sniff window: buffered and to-disk families still pass the bar (1.69x to 2.82x, measured on a loaded machine); streaming is unchanged.

## Not in this release

The 0.8 exit, the routes running in web-net with the real customs-sec in a test deployment, waits for those crates and moves to 0.9.x (D-125).

## What's next

`0.9.0` is the polish pass: every accepted gap tried again, a fresh performance pass, and the security review run again, before any 1.0 candidate.
