# form-net v0.3.0 - Core

**Date:** 2026-10-23
**Compare:** [`v0.2.0...v0.3.0`](https://github.com/jamesgober/form-net/compare/v0.2.0...v0.3.0)

**Form parsing works.** v0.3.0 built the core that the 0.2.0 design lock specified: detection, urlencoded parsing and serializing, and the streaming and buffered multipart parsers, on parse-net's grammar, with no `unsafe`, no third-party dependency, and a core that runs without an allocator.

## What's in 0.3.0

- **urlencoded.** `parse_urlencoded(body)?.get("email")` for the common case, `parse_query` for query strings, `parse_urlencoded_with` for a route's own limits, lazy `pairs`, and the allocation-free `raw_pairs` and `decode_into`. `&` is the only separator, and a malformed `%` or invalid UTF-8 is refused rather than repaired. `Form` uses two allocations whatever the field count, wipes its values on drop, and never prints them.
- **Serializing.** `serialize_urlencoded`, `Serializer`, and `encode_into`, byte-identical to the WHATWG serializer for UTF-8.
- **Streaming multipart.** `MultipartParser` takes chunks of any size and returns one event per call. It never allocates after construction, never rescans a byte, and gives the same events, and the same errors at the same offsets, for every split of the same body. It refuses the constructs that front-end inspectors and back ends read differently: bare LF, header folding, duplicate headers and parameters, transfer encodings, nested multipart, `\"` in quoted values, `filename*` by default, and a missing close delimiter.
- **Buffered multipart.** `parse_multipart(content_type, body)?` with `field`, `file`, `fields`, `files`, and strict `field_one`; parts borrow the body, and text fields are checked as text at parse time.
- **Budgets.** Every limit of the design is checked before the bytes it governs are buffered, including file count, header lines, text total, preamble, epilogue, padding, and the anti-forgery token. A limit larger than the one containing it is capped by it, so `Limits::DEFAULT.with_max_body_bytes(4096)` is a complete configuration.
- **Errors.** One `Copy` error type with `status_hint`, stable `code`s, and a location; no error ever holds a value or a file name.

## Verification

- Unit tests on every path; WHATWG urlencoded cases with the WHATWG result beside form-net's; every multipart refusal with a minimal body; every limit at n and n + 1; split invariance at every byte, against a whole-body reference parser.
- Property tests (no panic on any bytes, split invariance on random bodies, budgets, serializer round trips), counting-allocator tests for every no-allocation claim, and attack tests for the threats the core covers.
- A visit counter on the delimiter matcher proves the search linear on adversarial bodies (all CR, near-miss delimiters) at 1-byte, 7-byte, and 4 KiB chunks.
- Eight fuzz targets, each run clean locally and for 60 seconds in CI.
- Local gate on Windows and WSL Ubuntu, stable and 1.85; a bare-metal `thumbv7em-none-eabihf` build without `std` or `alloc`.
- CI green on every platform before the tag.
